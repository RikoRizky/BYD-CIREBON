## PANDUAN CEPAT AGAR WEBSITE MUNCUL DI GOOGLE

Saya sudah menyiapkan semua yang perlu. Sekarang Anda tinggal ikuti 3 langkah simpel di bawah ini:

---

### LANGKAH 1: PUSH PERUBAHAN KE GITHUB (1 menit)

Buka terminal PowerShell di folder `d:\byd-cirebon` dan jalankan:

```powershell
git add -A
git commit -m "SEO: Add meta tags, keywords, structured data, unit pages, FAQ"
git push
```

Tunggu sampai selesai. Ini akan upload semua perubahan yang saya buat ke GitHub.

---

### LANGKAH 2: DAFTARKAN KE GOOGLE SEARCH CONSOLE (2 menit)

1. Buka: https://search.google.com/search-console
2. Klik "Tambahkan properti" atau "Add property"
3. Pilih "URL prefix" dan masukkan: `https://bydcirebon.id`
4. Pilih metode verifikasi (lihat opsi di bawah)

**Metode Verifikasi (pilih salah satu):**

**A) File HTML (paling mudah):**
- Google akan memberikan file HTML
- Download file tersebut
- Upload ke folder `d:\byd-cirebon\public\` (rename jika perlu)
- Klik "Verifikasi" di Google Search Console

**B) Meta tag (saya bantu):**
- Google akan memberikan meta tag
- Kirim ke saya kode verifikasi (contoh: `1a2b3c4d5e6f7g8h`)
- Saya akan tambahkan ke `index.html`
- Klik "Verifikasi"

**C) Google Analytics (jika sudah punya akun GA):**
- Hubungkan akun Analytics ke Search Console

---

### LANGKAH 3: SUBMIT SITEMAP KE GOOGLE (1 menit)

Setelah verifikasi berhasil:

1. Di Google Search Console, pilih properti `bydcirebon.id`
2. Cari menu "Sitemap" di sidebar kiri
3. Klik "Tambahkan sitemap"
4. Masukkan: `https://bydcirebon.id/sitemap.xml`
5. Klik Submit

---

## SUDAH SELESAI!

Setelah ketiga langkah di atas, Google akan mulai mengindeks website Anda dalam **3-7 hari**. Situs akan mulai muncul untuk pencarian seperti:
- "BYD Cirebon"
- "BYD Harmony"
- "Mobil listrik Cirebon"
- "BYD Atto 3"
- Dan banyak lagi!

## APA YANG SUDAH SAYA SIAPKAN?

✅ Meta tags (judul, deskripsi, keywords)  
✅ Geo tags (untuk SEO lokal)  
✅ Open Graph & Twitter Card (untuk sharing)  
✅ JSON-LD Structured Data (LocalBusiness, Product, FAQ)  
✅ robots.txt (mengizinkan Google untuk crawl)  
✅ sitemap.xml (daftar semua halaman)  
✅ Halaman untuk setiap model BYD (Atto1, Atto3, Dolphin, Seal, dll)  
✅ Halaman FAQ dengan schema FAQPage

## TIPS TAMBAHAN (OPSIONAL)

**Jika mau lebih cepat muncul:**
- Daftar Google Business Profile (untuk muncul di Google Maps): https://business.google.com/
- Buat artikel/konten tentang model BYD dan promosi
- Tingkatkan kecepatan loading situs (optimize gambar & caching)

**Pantau progress di Google Search Console:**
- Lihat berapa halaman yang sudah diindeks
- Lihat berapa banyak impressions (ditampilkan di Google)
- Lihat berapa banyak clicks (orang klik ke situs Anda)
